# Solar icon attribution

The `solar_icons` font atlas contains selected glyphs from **Solar Icons** by
480 Design, distributed through `@iconify-json/solar@1.2.5`.

- Source: https://www.figma.com/community/file/1166831539721848736
- Package: https://www.npmjs.com/package/@iconify-json/solar/v/1.2.5
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)

The stable purpose-to-icon-to-PUA mapping is stored in `solar-icons.json`.
